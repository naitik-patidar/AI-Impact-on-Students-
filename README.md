# Student AI Performance Analysis

A data-driven analytics project evaluating the correlation between Generative AI adoption and academic performance across different college departments. This project leverages Python and Pandas to extract, clean, and run multivariate analysis on a dataset containing 50,000 student records.

## 🔍 Key Insights & Discoveries

* The Academic Lift Winner: **STEM students** achieved the highest academic return on investment, leading the campus with an average GPA increase of **+0.218**.
* The Campus Equalizer: While STEM held the highest gain, performance jumps were remarkably consistent across all disciplines—Medical (+0.208), Humanities (+0.206), Arts (+0.205), and Business (+0.202) all demonstrated stable, parallel growth trends.
* Baseline Impact: On average, student cohorts utilizing GenAI workflows realized an approximate **+0.20 overall GPA improvement** over the baseline semester.
* Usage Distribution: Behavioral analysis reveals that weekly GenAI usage metrics are heavily **right-skewed**, indicating a massive base of casual users (0-8 hours/week) paired with a high-impact segment of technical power users.

## 🛠️ Tech Stack & Methods
* Language: Python 3.14
* Libraries: Pandas, NumPy
* Environment: Jupyter Notebook / VS Code
* Core Concepts:  Data Cleaning, Groupby Aggregations, Split-Apply-Combine Workflows, Univariate & Multivariate Exploratory Data Analysis (EDA).
